### Hi, I'm Urvashi 👋

I'm a Bioinformatician turning messy biological data — genomes, transcriptomes, spatial tissue images — into things that actually make sense.

I recently interned at **Evolvus Inc.**, where I segmented immune regions in H&E histology images using QuPath and analyzed 10x Visium spatial transcriptomics data to map how B cells, T cells, and macrophages cluster together in tissue.

**What I work with:**
- 🧬 NGS & RNA-seq pipelines — BWA, Bowtie2, STAR, GATK, SAMtools, DESeq2, Nextflow, Trimmomatic
- 🧫 Spatial transcriptomics & tissue imaging — 10x Visium, QuPath, Squidpy, SEAGAL, GSEApy
- 🤖 ML for genomics — PCA, Ant Colony Optimization for feature selection, classification pipelines (scikit-learn)
- 💊 Molecular modelling & drug discovery — docking & MD simulations (Schrödinger Maestro, GROMACS, AutoDock, PyMOL, PyRx)
- 💻 Programming — Python, R, SQL, Linux/Bash

**A few things I've built:**
- 🔬 [ngs-pipelineTB](https://github.com/urvashigawas/ngs-pipelineTB) — NGS variant-calling pipeline (FASTQC → BWA → SAMtools → BCFtools) built in Nextflow DSL2
- 🎗️ [oc-subtype-predictor](https://github.com/urvashigawas/oc-subtype-predictor) — classifying ovarian cancer subtypes from RNA-seq data using PCA, ACO-based feature selection, and ML models (SVM, RF, LR, XGBoost)
- 🧪 [salinomycin-breast-cancer-rnaseq](https://github.com/urvashigawas/salinomycin-breast-cancer-rnaseq) — DESeq2 pipeline studying the transcriptomic impact of Salinomycin on breast cancer cells
